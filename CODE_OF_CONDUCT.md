# Code of Conduct

## Our Standard

We want this repository to be a constructive and welcoming place for everyone.

Examples of behavior that help the project:

- being respectful and patient
- giving actionable technical feedback
- assuming good intent
- focusing discussion on the code, bug, or design problem
- helping newcomers understand context

Examples of unacceptable behavior:

- harassment or personal attacks
- abusive language
- trolling or deliberately disruptive behavior
- publishing private information without permission
- hostile gatekeeping

## Scope

This Code of Conduct applies to Issues, Pull Requests, Discussions, review comments, and other project communication channels.

## Enforcement

If you experience or observe behavior that harms collaboration, please report it privately through the contact path listed in `SECURITY.md` or by opening a neutral maintenance request if no private path is available.

Project maintainers may remove, edit, or reject comments, Issues, or contributions that do not align with this Code of Conduct.
